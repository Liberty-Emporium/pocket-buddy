# Pocket Buddy

A personal finance and budget tracking app with smart categorization and insights.

## Overview

Pocket Buddy helps you track your spending, categorize transactions automatically, and get insights into your financial habits. Built with Python and Django.

## Features

- **Smart Categorization** — AI-powered transaction categorization
- **Budget Tracking** — Set and monitor budgets by category
- **Insights** — Visual reports on spending patterns
- **Privacy** — All data stored locally

## Tech Stack

- **Backend:** Python, Django
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript

## Quick Start

```bash
# Clone the repo
git clone https://github.com/Liberty-Emporium/pocket-buddy.git
cd pocket-buddy

# Install dependencies
pip install -r requirements.txt

# Run the app
python manage.py runserver
```
